# aws-cloud-security

KT cloud TECH UP — 클라우드 보안·암호 프로젝트

AWS 기반 리눅스 Web·DB 서비스를 구축하고, IAM 권한 관리와 네트워크 접근 통제 및 보안 정책을 적용·검증하는 프로젝트입니다.

## 프로젝트 개요

- 기본 프로젝트: 클라우드 보안 구성 및 IAM 정책 수립
- 수행 기간: 2026.11.04 ~ 2026.12.01
- 수행 범위: 기본 4단계 및 각 단계의 도전과제
- 심화 프로젝트: 2026.12.02부터 진행

## 주요 수행 내용

| 단계 | 필수 과업 | 도전과제 |
| --- | --- | --- |
| AWS 환경 구축 | EC2 기반 Linux Web·DB 서비스 구축 | 도메인·DNS·메일 등 외부 서비스 연동 |
| IAM 권한 관리 | 사용자·그룹 생성 및 정책 적용 | 최소 권한 적용, 과도한 권한 점검·개선 |
| 네트워크 보안 | VPC·서브넷·보안 그룹 및 접근 통제 | 외부 접근·개방 포트 자동 점검 |
| 보안 정책 고도화 | 보안 장비·서비스 및 정책 적용 | 취약 설정 개선 및 재검증 |
