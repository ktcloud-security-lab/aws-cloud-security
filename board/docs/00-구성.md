# 00 · 인프라 구성

## 한 줄 요약
사용자의 요청은 **NAT EC2**(공인 IP를 가진 입구)를 거쳐 private 망의 **Web EC2**로 전달되고, Web EC2는 필요할 때만 **DB EC2**에 접속한다. 공격 트래픽은 모두 NAT EC2를 지나므로 이 지점에서 Snort로 검사할 수 있다.

## 전체 경로

```
사용자
  │  HTTPS (443)
  ▼
NAT EC2  (public-subnet-a, 공인 IP 있음)
  │  iptables DNAT: 들어온 80·443 을 Web EC2로 포워딩
  ▼
Web EC2  (private, 공인 IP 없음)
  │  Nginx :443 (자체 서명 인증서)
  │     └─ 80 으로 오면 443 으로 리다이렉트
  ▼  proxy_pass
  gunicorn 127.0.0.1:8000   (WSGI 서버, Flask 앱 2개 워커 실행)
  ▼
  Flask 앱 (app.py)
  │  글 읽기/쓰기 등에서 DB가 필요할 때만
  ▼  MySQL 프로토콜 (3306)
DB EC2  (private, 공인 IP 없음)
  └─ MySQL :3306  (board 데이터베이스)
```

### 각 구간이 하는 일

| 구간 | 하는 일 |
|---|---|
| **NAT EC2** | 유일하게 공인 IP를 가진 입구. `iptables`의 **DNAT**(목적지 주소 변환)로 들어온 80·443 트래픽을 Web EC2의 사설 IP로 넘긴다. private 서버가 인터넷에 나갈 때의 NAT 역할도 겸한다. |
| **Web EC2** | **Nginx**가 443에서 HTTPS를 받아(자체 서명 인증서) 내부의 **gunicorn**(127.0.0.1:8000)으로 전달한다. 80으로 오면 443으로 리다이렉트한다. gunicorn이 Flask 앱을 실행한다. |
| **DB EC2** | MySQL(3306)만 돈다. 공인 IP가 없고, 오직 Web EC2에서 오는 연결만 받는다. |

> 용어
> - **DNAT (Destination NAT)**: 들어온 패킷의 *목적지* 주소를 다른 주소로 바꿔 전달하는 것. 여기서는 "NAT EC2로 온 80·443" → "Web EC2"로 바꾼다.
> - **자체 서명 인증서(self-signed)**: 공인 인증기관이 아니라 서버가 스스로 만든 HTTPS 인증서. 브라우저가 경고를 띄우지만 암호화는 정상 동작한다.
> - **gunicorn**: Flask 같은 파이썬 웹 앱을 실제로 돌려 주는 WSGI 서버. Nginx와 Flask 사이에 있다.

## 왜 이렇게 나누나

- DB EC2와 Web EC2는 **공인 IP가 없어** 인터넷에서 직접 때릴 수 없다. 외부에 노출되는 건 NAT EC2뿐이다.
- 모든 외부 트래픽이 NAT EC2 한 곳을 지나므로, 여기에 **Snort**를 두면 인터넷 ↔ 내부 트래픽을 한 지점에서 검사할 수 있다.
- 단, **Web ↔ DB 트래픽은 NAT EC2를 거치지 않는다**(VPC 내부 경로로 직접 간다). 그래서 Web ↔ DB 사이의 접근 통제는 Snort가 아니라 **보안그룹**이 맡는다.

## 보안그룹 (인바운드 규칙)

보안그룹은 EC2로 들어오는(인바운드) 트래픽을 IP·포트 단위로 허용하는 가상 방화벽이다.

| 대상 | 허용 포트 | 허용 출발지 |
|---|---|---|
| **NAT EC2** | TCP 80, 443 | 내 IP /32 |
| **Web EC2** | TCP 80, 443 | 내 IP /32 |
| **DB EC2** | TCP 3306 | Web EC2 보안그룹 |

- **내 IP /32**: 실습자 본인 PC의 공인 IP 한 개만 허용한다는 뜻(`/32` = 주소 1개). 취약한 앱이므로 아무나 못 들어오게 한다.
- Web EC2가 NAT EC2 뒤에 있는데도 출발지가 NAT EC2가 아니라 **사용자 IP**인 이유: DNAT는 *목적지*만 바꾸고 *출발지* 주소는 그대로 두기 때문에, Web EC2 입장에서는 원래 사용자의 IP가 그대로 보인다.
- **DB EC2는 3306을 Web EC2 보안그룹에서 오는 연결만** 받는다. 특정 IP가 아니라 "Web EC2에 붙은 보안그룹"을 출발지로 지정하면, Web EC2의 IP가 바뀌어도 규칙을 고칠 필요가 없다.
