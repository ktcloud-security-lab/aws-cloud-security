- 후보 정책에 대한 사전 설정 유효성 검사
- 검토 및 승인 완료 후 운영 정책 적용
- 정책 적용 후 정상 동작 검증
- 탐지 정확성 및 오탐 가능성 검토
- 변경 이력 및 검증 결과 기록
- 정기적인 정책 적정성 검토

## 4. 보안 정책 파일 관리

실제 운영 중인 Snort 설정 파일 및 탐지 룰은 IPS 인스턴스의 접근이 제한된 로컬 Git 저장소에서 관리한다.

GitHub에서는 정책 관리대장, 변경 요청, 승인 및 검토 이력을 관리하며, 상세 탐지 조건과 내부 네트워크 정보는 공개하지 않는다.

신규 정책은 별도의 로컬 Git 작업 브랜치에서 작성하고, 설정 유효성 검사 및 변경 승인 절차를 거쳐 운영 환경에 적용한다.

운영 적용 및 재검증 완료 후 기준 정책 버전을 갱신하고 변경 이력을 기록한다.
