# Snort IPS 정책 관리대장

## 1. 정책 관리 현황

- 관리 대상: TEAM404 Snort IPS
- 최초 등록일: 2026-11-25
- 기준 정책 버전: v1.0.0
- 관리 방식: 로컬 Git 버전관리 및 GitHub 기반 변경·승인 관리

## 3. 정책 관리 원칙

- 정책별 SID 및 Revision 관리
- 정책 변경 전 기존 설정 백업
- 정책 변경 요청 및 담당자 검토
- 승인된 정책에 대한 설정 유효성 검사
- 정책 적용 후 정상 동작 검증
- 변경 이력 및 검증 결과 기록
- 정기적인 정책 적정성 검토

## 4. 보안 정책 파일 관리

실제 운영 중인 Snort 설정 파일 및 탐지 룰은 IPS 인스턴스의 접근이 제한된 로컬 Git 저장소에서 관리한다.

GitHub에서는 정책 관리대장, 변경 요청, 승인 및 검토 이력을 관리하며, 상세 탐지 조건과 내부 네트워크 정보는 공개하지 않는다.
