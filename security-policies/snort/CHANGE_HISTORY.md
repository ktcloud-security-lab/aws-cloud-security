# Snort IPS 정책 변경 이력

## 1. 변경 이력 관리대장

| 변경 일자 | 정책 버전 | 변경 내용 | 검증 결과 | 승인 상태 |
|---|---|---|---|---|
| 2026-11-25 | v1.0.0 | 기존 운영 정책 최초 등록 및 Git 버전관리 환경 구축 | 설정 유효성 검사 성공 | 검토 요청 예정 |

## 2. 변경 이력 관리 원칙

- 정책 변경 일자 및 담당자를 기록한다.
- 변경 사유와 변경 전·후 내용을 기록한다.
- 변경 요청 및 승인 관련 Issue, Pull Request를 연결한다.
- 변경 후 설정 유효성 검사 및 정상 동작 검증 결과를 기록한다.
- 이전 정책으로 복구할 수 있도록 버전과 백업 파일을 관리한다.

## 3. 비고

최초 정책 등록 과정에서 기존 운영 중인 Snort 탐지·차단 정책은 변경하지 않았다. 실제 운영 정책 파일과 백업은 IPS 인스턴스 내 접근이 제한된 관리 디렉터리에 보관한다.
