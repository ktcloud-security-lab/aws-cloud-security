| 1000003 | 기존 SYN 기반 포트 스캔 의심 탐지 정책 유지 | 신규 스캔 탐지 정책 추가를 통한 탐지 범위 확대 |
| 1000005 | 반복 HTTPS 연결 탐지 정책 유지 | 실제 로그인 실패 기반 탐지와 구분하여 관리 |
| 1000005 | 주석 SID와 실제 SID 불일치 수정 | 개선 완료 |

최초 정책 적정성 검토에서 확인된 SID 주석 오류를 v1.1.0 정책 변경 과정에서 수정하였다.

기존 반복 TCP SYN 중심의 탐지 정책을 보완하기 위해 다양한 TCP 플래그 기반 스캔 및 유해 트래픽 의심 탐지 정책을 추가하였다.

기존 정책의 임계값 적정성 및 실제 운영 필요성은 지속적인 모니터링을 통해 검토한다.
