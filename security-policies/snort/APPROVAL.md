# Snort IPS 정책 변경 요청 및 승인 관리

## 1. 변경 요청 및 승인 이력

| 요청 ID | 요청 일자 | 요청 내용 | 검토자 | 승인 상태 |
|---|---|---|---|---|
| S15-001 | 2026-11-25 | Snort 정책 관리 체계 구축 및 최초 정책 버전 등록 | 지정 예정 | 승인 대기 |

## 2. 변경 요청 필수 기록 항목

- 변경 요청 ID
- 요청 일자
- 요청 담당자
- 변경 대상 정책
- 변경 목적 및 사유
- 서비스 영향도
- 변경 전·후 내용
- 사전 검증 결과
- 검토자 및 승인자
- 승인 일자 및 결과
- 변경 후 정상 동작 검증 결과
- 관련 GitHub Issue 및 Pull Request

## 3. 승인 관리 원칙

정책 변경 요청은 GitHub Issue를 통해 관리하며, 변경 내용은 Pull Request를 통해 검토한다.

담당 팀원의 검토 및 승인 이후 정책을 적용하고, 승인 결과와 검증 결과를 변경 이력에 기록한다.

승인되지 않은 정책은 운영 환경에 적용하지 않는다.

## 4. 최초 변경 요청

- 요청 ID: S15-001
- 요청 목적: S-15 정책 관리 취약점 개선
- 요청 범위: 정책 버전관리, 변경 이력, 승인 및 정기 검토 절차 구축
- 운영 정책 변경 여부: 없음
- 설정 유효성 검사: 성공
- Snort 서비스 상태: 정상
- 승인 상태: 승인 대기

실제 승인 결과는 팀원 검토 완료 이후 기록한다.
