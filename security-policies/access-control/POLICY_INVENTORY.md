
# 접근 제어 정책 관리대장

| SG-005 | WAS | WEB 보안 그룹으로부터 TCP 8000 허용 | 적용 |
| SG-006 | DB | WAS 보안 그룹으로부터 TCP 3306 허용 | 적용 |

## 6. 운영상 예외 정책

| 예외 ID | 대상 | 유지 사유 | 보완 통제 | 검토 상태 |
|---|---|---|---|---|
| EX-001 | IPS 내부 전체 허용 | 인라인 패킷 전달 기능 유지 | INPUT DROP, SG, NACL | 유지 사유 검토 |
| EX-002 | NAT HTTP·HTTPS 허용 | 외부 웹 트래픽 전달 | FORWARD 필터링 | 유지 사유 검토 |
| EX-003 | IPS 아웃바운드 전체 허용 | 패킷 전달 및 운영 기능 유지 | IPS 검사, 내부 계층 접근통제 | 세분화 검토 |
| EX-004 | NAT 아웃바운드 전체 허용 | 내부 서버 외부 통신 지원 | NAT 패킷 전달 필터링 | 세분화 검토 |
| EX-005 | IAM 서비스별 FullAccess | 담당 직무의 인프라 운영 | 직무별 그룹 분리 | 권한 범위 추가 검토 |

운영상 예외 정책은 서비스 영향도와 보안 위험을 고려하여
정기적으로 허용 범위 및 보완 통제의 적정성을 재검토한다.

## 7. 관리 기준

정책 변경 시 변경 일자, 담당자, 변경 사유, 승인 여부 및
재검증 결과를 기록한다.

실제 IP 주소, AWS 계정 ID, 내부 리소스 식별자 및
상세 IAM 정책은 접근이 제한된 별도 증적 자료에서 관리한다.
